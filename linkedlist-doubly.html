Doubly Linked List

Deskripsi Teknis: Doubly Linked List adalah struktur data linear dinamis di mana setiap elemen (node) menyimpan sebuah nilai dan dua pointer referensi: satu menunjuk ke node sebelumnya (prev) dan satu menunjuk ke node berikutnya (next) di memori.

Waktu: O(1)
Ruang: O(1)
Analogi Dunia Nyata: Doubly Linked List mirip dengan rantai besi. Setiap cincin rantai (Node) terkait erat dengan cincin di depannya (Next Pointer) sekaligus cincin di belakangnya (Prev Pointer). Hal ini memungkinkan Anda menelusuri rantai dari depan ke belakang maupun sebaliknya dengan sama mudahnya.
